Slack Bot
A simple bot in slack that adds utilities and fun things like ping checks, cat facts, and jokes!

How to Use:
- /wasd-ping -- pings bot
- /wasd-help -- gives a list of commands
- /wasd-catfact -- gives a cat fact (https://catfact.ninja/fact)
- /wasd-joke -- sends a joke (https://official-joke-api.appspot.com/random_joke)
